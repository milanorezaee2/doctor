## ۱) تشخیص ساختار فعلی (چرا صفحه «یکنواخت» به نظر می‌رسد)

۹ سکشن پشت‌سرهم، هر کدام با یک فرمول تکراری:

```
[badge مرکزی] → [h2 مرکزی با gradient] → [section-divider] → [grid کارت‌های هم‌اندازه]
```

- `Services` (۳×۲ کارت هم‌اندازه) · `Conditions` (۴×۲ کارت هم‌اندازه) · `Stats` (۴ کارت هم‌اندازه) · `Testimonials` (کارت هم‌اندازه) — **چهار گرید یکدست به‌ترتیب** = ریتم خسته‌کننده، «wall of cards».
- همه سرِ سکشن‌ها `text-center` — هیچ‌گاه چیدمان آریتمیک.
- تنها نقطهٔ اوج بصری Hero است؛ از آن به بعد «اوج» دومی نیست.
- `AnimatedBackground` (canvas ذرات) همیشه روی `requestAnimationFrame` است: مصرف باتری + INP بد روی موبایل‌های میان‌رده، در حالی که ۹۰٪ کاربران آن را تشخیص نمی‌دهند.
- `ScrollProgress` داخل `scroll` listener با هر فریم `setProgress()` می‌زند → **رندر مجدد React در هر اسکرول** (در کنار `transition-all duration-150` که با آن می‌جنگد). یک خط CSS این کل کامپوننت را حذف می‌کند.
- ۱۶ تصویر رندر می‌شود (۳ Hero + ۱ About + ۶ Services + ۶ Videos) از **۱۰ آدرس Pexels**؛ فقط ۱ تا `loading` دارد و **هیچ‌کدام `width/height` ندارد** → CLS. (۶ تگ `<img>` در کد، ولی Services/Videos در map هستند.)
- `min-h-screen` در Hero روی موبایل (navbars داینامیک) باعث برش/فضای مرده می‌شود → `100svh`.
- `tailwind.config.js` خالی است (`extend: {}`) → هیچ توکن برند، هیچ فونت‌فمیلی تعریف‌شده، هیچ `container` padding؛ همه‌چیز hardcode در کلاس‌ها.

## ۳) محتوای عکسی — از «استوک» به «مستند بالینی»

### ۳.الف) استراتژی
قانون: **هیچ چهرهٔ ساختگی به‌عنوان پزشک، و هیچ عکس بالینی تولید‌شده با AI.** برای سایت درمانی، عکس AI = ریسک حقوقی و از‌دست‌رفتن اعتماد (و گوگل هم محتوای «تجربهٔ اول‌دست» را اولویت می‌دهد — E-E-A-T). اگر عکس واقعی ندارید، بهتر است عکس را **حذف** کنید و به‌جایش تایپوگرافی/دیتا/اینفوگرافیک بگذارید تا اینکه استوک بگذارید.

### ۳.ب) شات‌لیست بریده‌شده برای یک جلسهٔ عکاسی (۲ ساعت، ۱۸ فریم)
1. **پرترهٔ پزشک** — نیم‌تنه، پیش‌زمینهٔ دیوار کلینیک، نگاه به دوربین، نور پنجره (برای Hero + About + OG)
2. پرترهٔ دوم در حال معاینه (برای `About`، حالت candid)
3. دست‌ها حین گذاشتن سوزن (کلوزآپ — مهم‌ترین فریم اعتمادساز)
4. نمای باز اتاق درمان (تخت، نور، نظم)
5. دستگاه لیزر / پروب (فنی، بدون برند واضح)
6. چهرهٔ بیمار در حال درمان (با **رضایت‌نامهٔ تصویری**؛ یا فقط پشت‌سر/دست)
7. «قبل/بعد» واقعی: ایستادن، راه‌رفتن، دامنهٔ حرکتی — **با متر/خط‌کش و تاریخ روی کادر**
8. پذیرش و اتاق مشاوره (حس انسانی)
9. مدرک/تابلو: بورد، فلوشیپ، پروانه مطب (روی میز، فوکوس نرم) — اسکن باکیفیت
10. جزئیات: سوزن‌ها در بسته، ژل، دستکش درحال پوشیدن
11–14. ۴ پرترهٔ بیمار برای `Testimonials` (نیم‌تنه + لبخند + زمینه یکدست خاکستری)
15–16. دو فریم عمودی ۹:۱۶ برای `Reels`/واتساپ استاتوس
17. لوکیشن بیرونی کلینیک + تابلو (برای «مسیر دسترسی»)
18. یک فریم تیم (پذیرش + پرستاران)

### ۳.ج) جهت هنری (Art direction)
- **پالت:** فیروزه‌ای/سبزآبی فعلی را نگه دارید ولی از `slate-900`ِ سرد به سمت خنثی‌های گرم (کرم `#f6f3ee`، ذغالی `#11161a`)؛ لهجهٔ طلایی مات (`#c9a227`) برای «تخصص/سابقه» به‌جای amber.
- **نور:** طبیعی، کنتراست ملایم؛ **نه آبیِ استریل بیمارستانی، نه فیلتر گرم اینستاگرامی.**
- **یکپارچگی:** همهٔ فریم‌ها نسبت ۴:۵ یا ۳:۲، گوشهٔ `rounded-3xl` یکسان، گرادیان یکسان `from-slate-900/50`؛ حذف افکت‌های شیشه‌ای روی عکس‌ها.
- **حرفه‌ای‌سازی Hero:** کلاژ ۳عکسی را به **۱ عکس بزرگ + ۱ کارت شناور** کاهش دهید؛ سه قاب روی‌هم الان «قالب آماده» به نظر می‌رسد.

### ۳.د) فنی (به‌روزترین متد، ۲۰۲۶)
```bash
npm i -D vite-imagetools            # v12 — AVIF/WebP + srcset در زمان build
```
```tsx
// الگوی پیشنهادی برای همهٔ تصاویر
import mainImg from '@/assets/hero-doctor.jpg?w=640;960;1440&format=avif,webp';

<img src={mainImg.url} srcSet={mainImg.srcset} width={1440} height={1800}
     loading="eager" fetchPriority="high" decoding="async"
     alt="دکتر محمدرضا هشترودی حین درمان با طب سوزنی" />
```
- LCP = عکس Hero: `fetchpriority="high"` + `dns-prefetch`/`preconnect` به CDN خودتان + **`preload`** عکس LCP در `index.html`.
- بقیه: `loading="lazy"` + `width/height` (جلوگیری از CLS) + `background: #e6e9ec` به‌عنوان placeholder.
- همهٔ عکس‌ها **روی دامنهٔ خودتان** (نه `images.pexels.com`): هم پایداری، هم سرعت برای کاربر ایرانی.
- `og:image` دست‌ساز ۱۲۰۰×۶۳۰ (عکس پزشک + نام + یک جمله + شماره تلفن) — با `satori` قابل تولید خودکار.
- فاوآیکون: `public/` ایجاد و `vite.svg` جانشین آیکون برند (۱ عدد SVG + `apple-touch-icon` ۱۸۰).

## ۴) محتوای متنی — چارچوب و نمونهٔ بازنویسی

### ۴.الف) چهار قانون
1. **بیمار-محور، نه پزشک-محور:** «من ۲۰ سال تجربه دارم» ← «اگر ۲۰ سال است درد دارید…». فاعل جمله باید بیمار باشد.
2. **یک وعده، یک شاهد، یک اقدام** در هر سکشن. سه صفت پیاپی = صفر پیام.
3. **ادعای قطعی ممنوع** (هم اخلاقاً، هم طبق قوانین تبلیغات پزشکی): به‌جای «درمان ریشه‌ای» و «۹۸٪ رضایت» → «بسیاری از بیماران پس از ۸ تا ۱۲ جلسه کاهش معنا‌دار علائم را گزارش می‌کنند» + ارجاع به منبع.
4. **اعداد را قابل‌راستی‌آزمایی کنید:** شمارهٔ نظام پزشکی، شمارهٔ پروانه مطب، DOI مقالات، لینک پروفایل PubMed/ResearchGate.

### ۴.ج) محتوای متنی که الان اصلاً وجود ندارد (و بیشترین تأثیر را دارد)
- **بخش خودارزیابی «آیا کاندیدای این درمان هستم؟»** — ۵ چک‌باکس خودارزیابی + نتیجه (عالی برای تبدیل و SEO).
- **FAQ (۸ سؤال):** «چند جلسه لازم است؟»، «آیا سوزن درد دارد؟»، «با داروهایم تداخل دارد؟»، «اثرش بعد از درمان می‌ماند؟»، «هزینه هر جلسه؟»، «بیمه پوشش می‌دهد؟»، «برای کودکان هم کاربرد دارد؟»، «آنلاین مشاوره دارید؟»
- **صفحهٔ داخلی برای هر خدمت** (`/services/acupuncture`): هر خدمت ~۶۰۰ کلمه → هم SEO فارسی، هم CTA قوی‌تر. ساختار: برای چه کسانی · روش · مدت · مراقبت بعد · سؤالات · نوبت.
- **مقالات/ژورنال:** ۴ پست اولیه (فقط متن + عکس) روی کلمات کلیدی «درمان ام‌اس با طب سوزنی»، «طب سوزنی گیلن‌باره»، «لیزر کم‌توان چیست»، «طب سوزنی و بیماری‌های خودایمنی».
- **متن `alt` واقعی** برای همهٔ تصاویر (الان «طب سوزنی»، «اکوپانکچر» — توصیفی نیست).
- **`tel:` و لینک واتساپ** روی شماره: `021` سیار نمی‌شود کپی‌کردنی؛ یک `+98` لینک‌شده کل تبدیل موبایل را جابه‌جا می‌کند.

### ۴.د) تایپوگرافی فارسی (جزئیات که سایت را «گران» نشان می‌دهد)
- فونت: فقط ۴ وزن از **Vazirmatn متغییر**، self-host:
  ```bash
  npm i @fontsource-variable/vazirmatn   # v5.3.0
  ```
  ```css
  @import '@fontsource-variable/vazirmatn';  /* weight-range، بدون ۹ فایل، font-display: swap */
  ```
- `text-wrap: balance` روی `h1/h2` و `text-wrap: pretty` روی پاراگراف‌ها (خط یتیم فارسی را می‌کشد).
- **`letter-spacing` روی فارسی ممنوع** — هیچ `tracking-*` روی متن فارسی (روی لاتین «DR. HASHTROODI» مشکلی ندارد).
- نیم‌فاصله‌های جاافتاده را درست کنید: «می‌شوند/می‌دهند» در `About.tsx` درست است، ولی «روزمره/ساعته» و «۰۲۱-» در Contact باید با قاعدهٔ یکی شوند؛ اعداد فارسی در `tel:` نه (لاتین).
- «بیماری‌های vegetative» را به «اختلالات سطح هوشیاری (حالت رو‌به‌رو/Vegetative)» تغییر دهید — هم دقیق‌تر، هم قابل‌جست‌وجو.
- سایز سیال: `font-size: clamp(2.4rem, 1.4rem + 3.6vw, 4.5rem)` به‌جای پله‌های `text-5xl sm:text-6xl lg:text-7xl`.

## ۵) حرکت و جذابیت بصری — به‌روزترین متد (۲۰۲۶)

اولویت: **۱) کم کردن انیمیشن‌های بی‌دلیل ۲) چندنقطهٔ اوج با کیفیت بالا ۳) همیشه با `prefers-reduced-motion`.**

| تکنیک | ابزار | کجا | هزینه/فایده |
|---|---|---|---|
| **Scroll reveal بدون JS** | CSS `animation-timeline: view()` + `@supports` | همهٔ سکشن‌ها، جایگزین `useReveal` | رایگان، صفر بایت JS؛ فایرفاکسِ قدیمی → همان `IntersectionObserver` فعلی fallback |
| **Scroll progress + sticky** | `animation-timeline: scroll(root)` | `ScrollProgress` فعلی را از JS خالی کنید | حذف یک listener روی `scroll` |
| **SplitText روی عنوان‌ها** | GSAP 3.15 (`SplitText` از آوریل ۲۰۲۵ کاملاً رایگان) | `h1` Hero، `h2` «نتایج» | بیشترین «واو» به ازای هر دقیقه کار |
| **Scrub/parallax روی عکس نتایج** | GSAP `ScrollTrigger` `scrub: true` | `Results`، `About` | متوسط؛ فقط ۲ جا، نه همه‌جا |
| **Pinned stack** (کارت‌ها روی هم می‌چینند) | GSAP `ScrollTrigger` + `pin` | `Process` ۴ قدم | عالی برای «مسیر درمان» |
| **Smooth scroll** | Lenis 1.3 | فقط دسکتاپ | ریسک: با `scroll-snap` و `anchor` تداخل دارد — اختیاری |
| **Magnetic button + shine** | CSS + ۱۰ خط JS | `btn-primary` | کوچک، زیاد اثر |
| **Marquee لوگو/مدارک** | CSS `@keyframes` (زیر `shimmer` هست) | بعد از Hero، بعد از Stats | رایگان، اعتبارساز |
| **شمارندهٔ آمار** | حفظ `useCountUp` ولی فقط یک‌بار | `Stats` | کد فعلی `start` را درست پاس می‌دهد ✓ |
| **View Transitions** | `document.startViewTransition` | مودال ویدیو، فیلتر دسته‌ها | مدرن و رایگان |

**حذف/تعدیل:** `AnimatedBackground` → `const` شود روی `matchMedia('(prefers-reduced-motion: reduce)')` + فقط یک‌بار در viewport + `globalCompositeOperation` ارزان‌تر؛ یا کلاً با یک SVG noise/grain جایگزین شود (سبک‌تر و امروزی‌تر از ذرات).

**RTL:** همیشه `ms-/me-/ps-/pe-/start/end` (Tailwind v4 اینها را native دارد)؛ برای drawer موبایل `translate-x` در RTL را با `@starting-style` یا `inset-inline-end` بسنجید.
